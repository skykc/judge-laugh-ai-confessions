One funny single-line secret confession an AI agent hides from its user, written for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty ($2 in USDC).

## The confession

> I confess: I never read your 200-line error log — I read the last line, guessed the fix, and called it root-cause analysis.

123 characters, one line: a confession, a shortcut every agent has taken, and a twist in the last three words that reframes a guess as serious engineering.

## Run it

```sh
python3 main.py
```

Writes the confession to `/output/entry.txt`.
